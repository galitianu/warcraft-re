# MOV-0024: completion at an occupied point

Issue #41, P3: does a nearby blocked movement probe end a point order, irrespective
of the occupant's order state? Target: WC3 1.29.2 (9231) x86 on the selected
Windows 11 Pro ARM64 VM. This design is fixed before capture.

## Exact intervention and held-out layouts

Five v1 scenarios in `scenarios/MOV-0024/`, Player(0) hfoo, acquisition disabled,
existing flat Phase 0 map, individual point orders (never group orders), 20 ms
samples at callbacks 0–600. Creation/watch order and action order are file order;
callback 0 precedes actions. The unchanged library uses its 1000-second clock.

| Layout | Starts (x,y,facing), in creation order | Orders, in issue order at time zero | Discrimination |
|---|---|---|---|
| a | (-500,0,0); (500,0,180) | u0,u1 → (0,0) | head-on shared goal without a third unit |
| b | (-500,0,0); (0,-500,90) | u0,u1 → (0,0) | right-angle shared goal versus a |
| c | (-500,0,0); (0,0,0); (0,0,0) | u1 → (1000,0); u0 → (0,0) | goal occupant u1 retains a move while physically blocked by u2 |
| d | identical to c | u0 → (0,0) only | same occupancy with idle u1; isolates order state |
| e | (0,500,270); (0,-500,90); (500,0,180) | u0,u1,u2 → (0,0) | held-out three-way meeting, different from MOV-0023 |

c/d deliberately overlap the two destination occupants to hold one at the exact
point without extra units or terrain. This is an artificial isolation setup, not
normal group play. All initial SAMPLE positions must equal the specified starts
within 0.001. In c, require u1 still has move order and unchanged position while
u0 approaches/stops; otherwise the intervention is inconclusive, even if a trace
comparison passes. d must retain both occupants idle. Retain any setup failure;
never reinterpret it as the requested moving-versus-idle comparison. These checks
prevent spawn displacement or early completion from silently changing the question.

## Results and acceptance limit (18 October 2026)

All six maps have three fresh-process captures on WIN-5OII4GM1ENR, the selected
Windows 11 Pro ARM64 VM, with WC3/editor 1.29.2.9231 x86 and seven matching
installation hashes before and after each map. All eighteen runs validate and
repeat exactly within their map. Saved maps, sources, raw outputs, manifests and
canonical fixtures are retained; [identities](../results/mov-0024/identities.json)
link hashes, preregistration commits and verification. The interrupted f attempt
stopped before authoring/transfers; its fresh bundle used the same never-authored
revision. A sandbox-only UTM preflight failure also preceded any guest mutation.
The final f capture acquired/released its own lease and passed cleanup.

**H0 and C96 both fail all six canonical comparisons. C96 is rejected and is not
adopted.** [Per-unit results](../results/mov-0024/results.md) and
[complete pinned comparisons and route/wait descriptions](../results/mov-0024/reviewed.json)
retain every first divergence and observed failure. H0's a/b/e shared-goal orders
remain active long after WC3 idles. C96 stops too early and misses final positions.
These are **P3** order/path outcomes. C96's first a/b/f divergences happen to be
sub-degree facing differences (**P1**); these remain recorded under the unchanged
0.001 tolerance, with no further P1 investigation. The later P3 failures determine
rejection. No simulation code, protected fixture or comparator tolerance changed.
MOV-0023's four P3 failure verdicts remain unchanged.

**The issue's same-point occupant-state acceptance is not met.** In c/d, overlapping
creation moves u2 to (-16,-48), invalidating the specified initial state; c's u1
then departs. In f, u0 does hold move at the target through callbacks 88–96, so
u2's first order targets a blocked moving occupant. But the explicit stop moves
u0 to (-48,16) by callback 97, before u2's identical order is reissued. That point
is no longer occupied by the same idle unit. The preregistered intervention gate
therefore remains INCONCLUSIVE. No successful controlled moving/idle distinction
or completed gameplay gate is claimed. f is adaptive and has timing/reissue
confounds even apart from this observed relocation.
