# MOV-0026: relocation at an explicit stop

[Issue #49](https://github.com/galitianu/warcraft-re/issues/49), user authorized
19 October 2026. **P3:** an occupied point moved when its occupant stopped in
MOV-0024-f, defeating the moving/idle comparison. This is a new four-layout
experiment, not a seventh MOV-0024 layout. MOV-0025 is reserved by #46.

## Question, scenarios and acceptance

Does stopping a blocked Footman change its position by the next 20 ms sample,
and do new positions lie on pathing-cell centers? Distinguish this from stopping
while still moving and from simple translation of an existing endpoint.

Use the existing flat Phase 0 map, Player(0) hfoo, acquisition disabled, ordinary
individual point orders, oracle-v1, 600 callbacks at 0.02 s (12 s), 1000 s clock.
Create/watch u0 then u1. At callback 0, sample first, then issue u0's move followed
by u1's move. Only u0 receives the later stop, after that callback's sample.

| Layout | u0 start/facing | u1 start/facing | Both move targets | Stop u0 | Separates |
|---|---|---|---|---|---|
| a | (-500,0), 0 | (500,0), 180 | (0,0) | callback 90, 1.8 s | early in observed blocked wait |
| b | same | same | same | callback 96, 1.92 s | later stop; compare MOV-0024-f without the third unit |
| c | same | same | same | callback 80, 1.6 s | moving control before observed blocked wait |
| d | (-484,16), 0 | (516,16), 180 | (16,16) | callback 96, 1.92 s | half-cell translation; fixed grid versus translated endpoint |

Exact v1 files: `scenarios/MOV-0026/`. No additional variants, spawn overlaps,
placement API, model fit, or adoption. Existing MOV-0024-a is the natural-completion
baseline (u0 first idle at 98, (-48,48)); MOV-0024-f's explicit-stop observation
is prior evidence, not a fresh held-out result. The new maps are held out until
this design and all predictions are committed.

Setup gate: initial positions match the specified starts within 0.001; u0 retains
move at K-2,K-1,K, where K is the stop callback. In a/b/d those three positions
must be equal within 0.001; in c at least one coordinate must change beyond 0.001.
These are *observed stationary/moving* conditions, not proof of an internal blocker.
Failed setup is INCONCLUSIVE for the intervention, even if canonical traces pass.

## Frozen competing predictions

- **H0, unchanged footman-v4:** full traces in `results/mov-0026/predicted/` and
  `predictions.json`, including scenario/trace hashes, runner hash, source digest,
  build identity, per-unit descriptions and stop-transition predictions. Built
  at c580105, AppleClang Release, source unchanged through de02d36. No simulation
  source differs from this model. The model can settle facing after a stop, so
  the full trace is authoritative; qualitative claims do not replace it.
- **S (stop in place):** in every valid layout, the first sample after stop has
  order 0 and x/y equal to the pre-action sample within 0.001.
- **B (blocked-only grid relocation):** a/b/d first post-stop samples are idle,
  displaced beyond 0.001 in at least one coordinate, with **both** coordinates
  16 modulo 32 within 0.001. c is idle and remains at its pre-stop position.
- **G (unconditional grid endpoint):** all four first post-stop samples are idle
  with both coordinates 16 modulo 32 within 0.001, including moving control c.

These are qualitative alternatives, not fitted C++ candidates. The grid phase
comes from prior MOV-0024-a/f endpoints, not new captures. No unique free-cell
selection algorithm or exact endpoint is asserted by B/G. d uses (16,16), not a
whole-cell shift: a translation-covariant copy of a center endpoint would have
coordinates 0 modulo 32, distinct from B/G's 16 modulo 32. Compare d minus (16,16)
with b descriptively; a difference does not alone identify a collision algorithm
because approach/path decisions may also depend on grid phase. Record that limit.

For each hypothesis/layout record SURVIVES, REFUTED, or INCONCLUSIVE from the
fixed setup and first-post-sample rules in `tools/predict_mov0026.py`. Overall
survival requires all four valid layouts; any valid counterexample refutes it.
If setup is missing without a counterexample, the overall result is inconclusive.
A surviving coarse rule is not an accepted gameplay model. BIN-0001 in draft
PR #47 concerns failed-search completion with unresolved conditions, not this
relocation test; it is not added retroactively to MOV-0024 or fitted here.

## Observed results

Preregistration commit `02fb00d12e8ff6c73bb84482db0ad49eb92ecda2` preceded all
four maps. Twelve fresh WC3 processes on the verified WIN-5OII4GM1ENR / selected
Windows 11 Pro ARM64 VM validate and repeat exactly within each layout. All maps
match their source; installation, source and transfer checks passed. Complete
[identities](../results/mov-0026/identities.json), [per-unit results](../results/mov-0026/results.md)
and [pinned comparisons/transition decisions](../results/mov-0026/reviewed.json)
retain passing, failing and inconclusive outcomes.

- **a/b:** setup passes. The first samples after stops at callbacks 90/96 are
  (-48,48), displaced 51.174363 world units from (-30.222656,0.012695). Both
  coordinates are exactly 16 modulo 32 in emitted observations. u0 stays there
  through callback 600. The unchanged model leaves u0 in place and u1 moving
  indefinitely; these are **P3** differences. WC3 idles u1 one sample after u0.
- **c:** setup passes. Stopping while moving at callback 80 leaves u0 exactly at
  its pre-action sampled coordinates. The **entire canonical trace passes** H0,
  including both units. This refutes unconditional grid-endpoint prediction G.
- **d:** WC3 idles u1 at 89 and u0 at 95, before u0's stop at 96. The required
  pre-stop move-order condition fails, so the translated intervention is
  **INCONCLUSIVE**, not evidence for or against a stop relocation rule. H0 keeps
  u1 moving and predicts u0's first idle only after the stop; canonical comparison
  fails first at 89/u1/order (**P3**). u0's natural idle endpoint is not a cell
  center, but the preregistered hypotheses concern explicit stops under their
  specified setup, so this is not used to redefine those hypotheses after capture.

S (always stay in place) and G (every stop ends on a center) are refuted. B
(blocked-only relocation to centers) survives a/b/c but is **INCONCLUSIVE overall**
because d did not realize its intervention. No complete cell-selection rule is
established, and no rule is adopted. Internal blocker state, precise within-sample
timing and which occupancy condition triggers repositioning remain unobserved.
The natural-completion MOV-0024-a endpoint matches a/b; the third-unit MOV-0024-f
endpoint differs. Those are comparisons to prior evidence, not new controls.

H0 passes 1/4 layouts and fails 3/4. No model, old fixture or tolerance changes.
The finite regression's PASS means it reproduces these exact verdicts and the
inconclusive intervention, not that stop relocation or issue #41 is solved.
The twelve runs complete this bounded evidence increment (#49); the controlled
moving/idle same-point gate in #41 remains open. No fifth MOV-0026 layout is added.
